# Custom HTML slides

Two different “HTML” features:

1. **Whole slide as HTML** — In a slide folder, use `slide.html` instead of `slide.md`. The deck renders that file in an **iframe** (full document: `<html>`, CSS, small scripts in the sandbox). See the **HTML slide demo** later in the deck.

2. **Working area** — `working-area/slide.html` (or `.md`) is the panel you open with **F** / the flip control: live preview next to the slide, not the main slide canvas.

Use HTML slides when you need layout or components that are awkward in markdown alone.
