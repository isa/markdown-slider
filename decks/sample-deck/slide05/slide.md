This is the **content** layout (also the default if you omit `layout:`).

- Title and subtitle render in the deck header row with a gradient rule.
- Body scrolls when it overflows.
- Works well for talks, specs, and mixed markdown.

### Small heading

Supporting text demonstrates line height and spacing from the active theme.
